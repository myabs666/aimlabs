# AimVision v0.1.0

`v0.1.0` 是 AimVision 的首个公开预览版本，整理了 Windows 上从画面识别、校准到闭环控制的完整运行流程。

## 下载

Windows 10/11 x64 用户下载：

`AimVision-v0.1.0-windows-x64.zip`

解压后运行 `AimlabVision\AimlabVision.exe`。这是目录式程序，不能只复制 EXE；必须保留同目录 `_internal` 文件夹。

## 主要功能

- DXcam 桌面捕获与 OpenCV 静止圆靶检测。
- 中文 GUI、环境检查、HSV 调色预览和 F10 脱敏前截图入口。
- 双轴基础校准与低速闭环学习。
- 普通高速控制的三目标路径规划、透视映射、新帧确认和残差修正。
- 实验性极高速控制以及画面无响应自动暂停。
- 前台窗口、客户区尺寸和输入结果保护。
- JSONL 日志、离线模拟、回归测试和项目内隔离运行环境。

## 首次运行

1. 启动 Aimlabs，并使用无边框窗口模式。
2. 运行 AimVision 的“环境检查”。
3. 设置与游戏一致的水平 FOV。
4. 使用“调色预览”确认目标检测结果。
5. 完成基础校准，再使用普通高速控制验证准确率。

详细操作见仓库 [README](../../README.md)。

## 验证

- 运行项目测试套件。
- 运行离线合成场景模拟。
- 使用 PyInstaller 生成 Windows x64 目录式程序。
- 发布压缩包同时提供 SHA-256 校验值。

## 已知限制

- 当前版本主要支持静止圆靶。
- 更换分辨率、水平 FOV、灵敏度或输入设置后必须重新校准。
- DXcam 只能获取显示器实际呈现的内容，游戏被其他窗口遮挡时不应启用控制。
- 本项目不保证与所有 Aimlabs 版本兼容，也不提供规避检测或处罚的保证。
